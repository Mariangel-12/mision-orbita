# Misión Órbita

## Descripción
Simulador básico de exploración espacial en Python. En este primer avance se
desarrollan cuatro algoritmos independientes que representan la preparación de
una misión: cálculo de recursos, verificación de combustible, verificación del
soporte para la tripulación y autorización de lanzamiento.

- avance1/ejercicio2_combustible.py
- avance1/ejercicio3_soporte_tripulacion.py
- avance1/ejercicio4_autorizacion.py
- documentacion/avance1.pdf

## Instrucciones para ejecutar
1. Instalar Python 3.
2. Abrir una terminal en la carpeta mision-orbita.
3. Ejecutar el programa deseado, por ejemplo: python avance1/ejercicio1_recursos.py
4. Ingresar los datos que solicita el programa por consola (números enteros positivos).

## Convenciones y estilos
- Variables en snake_case, con nombres descriptivos y en minúscula.
- Constantes en MAYÚSCULAS con guion bajo, declaradas al inicio del archivo.
- Indentación de 4 espacios.
- Cada archivo inicia con un encabezado con nombre, curso, integrante, fecha, versión y descripción.
- Bloques de código separados y precedidos por un comentario de su propósito.
- Mensajes de commit que describen el cambio realizado.
